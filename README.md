# STAT240-Final-Project
This is a group project for STAT 240 that I worked on with 3 teammates. 
We analyzed a dataset consisting of 2000 students to determine whether there is a positive correlation between sleep and GPA.

## Files
- `STAT240_Final_Project.Rmd` — full analysis: data cleaning, regression, plots, and write-up
- `STAT240_Final_Project.html` — knitted report (view this for the formatted output)
- `student_lifestyle_dataset.csv` — the dataset used (source: Kaggle, by Sumit Kumar)
